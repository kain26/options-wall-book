# Bilingual Trading Glossary

| Chinese | English rendering | Policy |
| --- | --- | --- |
| 期权墙 | options wall | Generic concept; use **Call Wall** and **Put Wall** for named levels |
| 买方篇 | Buyer Edition | Book-edition title |
| 做市商 | market maker | Do not use “dealer” unless discussing dealer positioning |
| 做市商对冲 | market-maker hedging | Preserve the mechanical, non-directional framing |
| 当天到期 | zero-days-to-expiration (0DTE) | Define on first important use |
| 正 Gamma | positive gamma | Counter-trend hedging: sell rallies, buy dips |
| 负 Gamma | negative gamma | Pro-cyclical hedging: buy rallies, sell declines |
| Gamma Flip | Gamma Flip | Keep English and capitalization |
| 看涨墙 / 看跌墙 | Call Wall / Put Wall | Keep English and capitalization |
| 价格行为 | price action | Use “trend” only where the Chinese explicitly narrows the meaning |
| 流动性猎杀 | liquidity sweep | Avoid sensational alternatives |
| 减震器 / 加速器 | shock absorber / accelerator | Preserve the recurring metaphor |
| 复盘 | review / trade review | Choose by sentence context |
| 仓位 | position / position size | Choose by sentence context |
| 止损 | stop / stop-loss | “Stop” in execution prose; “stop-loss” in definitions |
| 学费 | tuition paid to the market | Preserve the author’s metaphor |

GEX, VWAP, GVP, Delta, Gamma, Vanna, Charm, Theta, Pin, Long Call, and Long Put remain unchanged.

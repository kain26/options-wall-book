# 期权墙 · 买方篇

《SPX 日内实战入门（买方篇）》的响应式网页阅读版。

## 在线阅读

[打开《期权墙 · 买方篇》网页版](https://options-wall-book.mmoptions.workers.dev/)

## 本地运行

```bash
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址。

## 构建

```bash
pnpm build
pnpm preview
```

生产文件生成在 `dist/`。

## 内容位置

- 正文：`content/chapters/`
- 网页：`src/`
- 插图：`public/images/`

代码与原创内容采用不同许可，详见 `LICENSE.md`。

# 导读：半小时看懂期权墙（GEX 地图）

这一节带你学会**认图**——在你用的期权分析软件或交易终端上，找到 Call Wall、Put Wall、Gamma Flip 画在哪里。**为什么**有墙、**怎么用**墙，分见第 2、3 章。

---

## 一张 GEX 图谱长什么样

<figure class="book-figure">
  <img src="/images/figures/figure-001.webp" alt="图 导读-1  GEX 图谱示意（纵轴 Strike · 横轴 Gamma）" loading="lazy" decoding="async" />
  <figcaption>图 导读-1  GEX 图谱示意（纵轴 Strike · 横轴 Gamma）</figcaption>
</figure>


**图 导读-1** 就是打开任意期权分析工具的 GEX（Gamma Exposure）功能后，通常会看到的样子。对着它，先认几样东西：


| 元素     | 在图上找什么               |
| ------ | -------------------- |
| **纵轴** | 行权价                  |
| **横轴** | 柱长 = 该 strike 对冲压力大小 |
| **绿色** | Call 侧               |
| **红色** | Put 侧                |


**柱长不等于未平仓合约数。** 它大致是「OI × 单张合约的 Gamma」——两个因子相乘。Gamma 在平值附近最高、往两边快速衰减，到期越近衰减越陡；所以 0DTE 下，远端行权价上堆再多 OI，柱子也几乎看不见，反倒是现价附近 OI 一般的 strike 能撑起一堵墙。「筹码堆在哪」和「做市商此刻被迫对冲哪里」，是两张不同的图。

**有的软件会把 x、y 对调**——行权价横着排、柱子竖着画。别被方向吓到，表里那几样元素不变。

**颜色要确认一次。** 大多数工具按「Call 侧 / Put 侧」上色，但也有工具是按**净 GEX 的正负**上色（正为绿、负为红）。两种画法在图上长得很像，认错了，墙就标反了。第一次用一个新软件，先翻一下它的图例或说明。

不必会算柱子。**先学会认图**——就像看天气预报的云图，不需要会建气象模型。

> *全书插图与机制示意均为示意，非信号。*

## 三根线：在图上标哪里

<figure class="book-figure">
  <img src="/images/figures/figure-002.webp" alt="图 导读-2  Call Wall / Gamma Flip / Put Wall 三价位" loading="lazy" decoding="async" />
  <figcaption>图 导读-2  Call Wall / Gamma Flip / Put Wall 三价位</figcaption>
</figure>


**图 导读-2** 把满屏柱子收成三条线——Call Wall、Gamma Flip、Put Wall。对照它，在自己的软件上标出来：

- **Call Wall**：**现价上方**最厚的那根绿柱。别在整张图上找最厚的，要在现价上方找。
- **Put Wall**：**现价下方**最厚的那根红柱。同理，只在现价下方找。
- **Gamma Flip**：它不是柱状图上绿红交界的那一格，而是软件把**净 GEX 随现价变化**算成一条曲线之后，这条曲线**穿过零轴**的那个价位（有的软件叫 Zero Γ、Flip、Major Gamma）。你现在只要记住一句：现价在它上方，今天偏「稳」；现价掉到它下方，今天偏「躁」。

能在自己的软件上把这三处指出来，这一节的目的就达到了。它们各代表什么性格、具体怎么用，第 2、3 章再说。要是软件还标了 **Net GEX ±**，先记下此刻是正是负就行。

## 读图时别搞混两件事


| 看什么               | 操作                             |
| ----------------- | ------------------------------ |
| **盘前**            | 多为 **OI GEX** 快照 → 标隔夜三价       |
| **盘中**            | 切 **Volume GEX** → 墙位可能和盘前不同   |
| **收盘前 30–15 分钟**  | 再对照 **OI**（Pin 段，**附录·日内节奏表**） |


OI（未平仓合约）是**昨天收盘结算出来的持仓，盘中不更新**；今天新开的仓，只体现在成交量里。所以「墙会动」不是软件抽风，是战场真的搬了家。

❌ 常见误读一：**只看开盘墙位用一整天** → 盘中墙会动，跟 Volume 版走。

❌ 常见误读二：**到期日没选对** → 把整条链（含本周、下周到期）的 GEX 当成今天的结构。做 0DTE，先把到期日过滤成**今天**，再看图。

## 期权墙，去哪儿看

期权墙（GEX 地图）不挑工具。如今能看 SPX 期权 Gamma 分布的地方不少——一些券商的高级行情、专门做期权流的平台、带期权模块的行情终端，大多都画得出来：

- 按行权价排开的 **Gamma / GEX 柱状图**（绿柱、红柱）
- **OI 版**与 **Volume / 实时版**的切换
- **按到期日筛选**（做 0DTE，这个功能是刚需）
- **Call Wall、Put Wall、Gamma Flip**（有的叫 Zero Γ、Flip、Major Gamma，只是名字不同）

各家的**算法和价位不必一致**，界面叫法也五花八门——**认准功能就行**：盘前用 OI 标结构，盘中用 Volume 跟主战场，尾盘对照 OI 读 Pin。本书不指定、也不推荐任何一家；**附录·参考文献**引用的外部统计只作概率校准，并不要求你用同一个数据源。

## 一、读前须知

**书中的四位数字**（0604、0123）都是 2026 年的交易日：0604 = 2026-06-04，指当天的 SPX 0DTE 复盘。

**期权是什么（一句话）**

期权 = 可以转让的承诺。

- **Call（看涨）**：有权在约定价买入标的
- **Put（看跌）**：有权在约定价卖出标的

买方付权利金；卖方收权利金并承担义务。本书只写买方（Long Call / Long Put）。

---

**一张合约的五个要素**


| 要素  | 英文         | SPX 0DTE 例   |
| --- | ---------- | ------------ |
| 标的  | Underlying | SPX 指数       |
| 行权价 | Strike     | 6800（示例）     |
| 到期日 | Expiration | 当天（0DTE）     |
| 类型  | Type       | Call / Put   |
| 方向  | Side       | Long / Short |


0DTE = 当天到期，时间价值衰减极快，越接近收盘越凶。

---

**四种基础姿势**


|              | Call | Put |
| ------------ | ---- | --- |
| **Long（买）**  | 赌涨   | 赌跌  |
| **Short（卖）** | 赌不涨  | 赌不跌 |


0DTE 买方特征：低胜率、高赔率、时间剧毒。方向对了，时间或 IV 仍可能让你赚不到。

---

**期权价格三条腿**

期权价格 ≈ 内在价值 + 时间价值（含 IV）


| 腿    | 直觉        | 0DTE 买方            |
| ---- | --------- | ------------------ |
| 内在价值 | 现在行权值多少钱  | 价内才有               |
| 时间价值 | 还没到期的不确定性 | 越接近收盘越少            |
| IV   | 市场预期的波动定价 | 事件日前偏贵，公布后可能 crush |


---

**四个希腊字母（直觉版）**


| 字母    | 回答什么            | 与本书关系            |
| ----- | --------------- | ---------------- |
| Delta | SPX 动 1 点，期权动多少 | 做市商对冲的「方向敞口」     |
| Gamma | Delta 变多快       | GEX 的原材料（第 2 章）  |
| Theta | 时间流逝，期权贬多少      | 买方剧毒；15:30 后尤其凶  |
| Vega  | IV 变，期权贵还是便宜    | 事件日、Vanna（第 3 章） |


Gamma 堆积画成地图，就是 GEX。先建立「做市商被迫对冲 → 影响价格」的画面，再读正文。

---

**为什么是 SPX**

- 欧式 + 现金交割：不会被半夜 assign；Pin、GEX 结构清晰
- 0DTE 流动性深：做市商对冲 footprint 可读性高

你买的期权，大多跟做市商成交。他们卖给你之后必须对冲 Delta——正文从这条链展开。

---

**示意数字 vs 复盘数字**


| 类型   | 怎么认                      | 怎么用                   |
| ---- | ------------------------ | --------------------- |
| 复盘数字 | 章节写明了具体交易日（如 0604）       | 对照当日结构，理解机制；不是次日照抄的信号 |
| 示意数字 | 概念章的地图、数字例子、ASCII 图；标有「示意」 | 学读法与逻辑；价位、时间与实盘可能不符   |


---

**GEX 数据与软件（不绑定产品）**

正文依赖 OI GEX（盘前结构）与 Volume GEX（盘中刷新）。市面专业期权分析工具大多提供：按 strike 的 Gamma 柱图、OI/Volume 切换、Call/Put Wall 与 Gamma Flip 标注。界面叫法各异，认准功能即可。本书不点名、不推荐具体产品。

## 二、英文术语表（含比喻速查）

**核心价位**


| 术语         | 中文      | 一句话                           | 不是什么   |
| ---------- | ------- | ----------------------------- | ------ |
| Call Wall  | 看涨墙     | Call 侧 Gamma 堆积最厚的行权价带；上方压力集中 | 不是铁顶   |
| Put Wall   | 看跌墙     | Put 侧 Gamma 堆积最厚的行权价带；下方支撑集中  | 不是铁底   |
| Gamma Flip | 零 Gamma | GEX 正负分界；市场性格开关（减震器 ↔ 加速器）    | 不是普通支撑 |


**形态与订单流**


| 术语              | 中文    | 一句话                       |
| --------------- | ----- | ------------------------- |
| Liquidity Sweep | 流动性扫单 | 假破关键位 → 扫止损 → 快速收回的总称     |
| Stop Run        | 停止单猎杀 | 故意刺穿整数关口下方 5–10 点，触发止损后收回 |


读法：Put Wall 上的假跌破收回 → 多称 Liquidity Sweep（如 0213）；纯整数止损位 → 称 Stop Run（如 0123）。

**正 / 负 Gamma 环境**


| 术语              | 直觉  | 做市商倾向        |
| --------------- | --- | ------------ |
| 正 Gamma / 正 GEX | 减震器 | 跌买涨卖 → 波动被抑制 |
| 负 Gamma / 负 GEX | 加速器 | 跌卖涨买 → 波动被放大 |


**比喻速查（非金融版）**


| 概念         | 比喻      | 一句话                  |
| ---------- | ------- | -------------------- |
| 正 GEX      | 减震器     | 涨了就卖、跌了就买，让价格稳       |
| 负 GEX      | 加速器     | 涨了追买、跌了追卖，让波动放大      |
| Call Wall  | 天花板     | 价格到这里，上面有卖压          |
| Put Wall   | 地板      | 价格到这里，下面有买盘          |
| Gamma Flip | 性格开关    | 线上稳、线下躁              |
| 做市商对冲      | 自动平衡机器人 | 不赌方向，只管把账算平          |
| GEX 地图     | 天气预报云图  | 先看今天什么性格             |
| Pin        | 收盘磁铁    | 尾盘价格被 OI 厚 strike 吸住 |

## 三、期权墙 · 一页纸实战速查表

【盘前三件事】
1. 日历 → 事件日/OPEX？
2. GEX → Call Wall / Put Wall / Gamma Flip（盘前OI版）
3. 地图 → 前日高低 + 事件时间线

现价 vs Gamma Flip：
  上方 → 偏减震器（区间、磨）
  下方 → 偏放大器（趋势、慎接飞刀）

【日内节奏】
盘前          → OI标墙位
开盘-30分钟   → 看成交重心是否偏离
10:00-15:00   → Volume主导，墙跟Volume版
尾盘30-15分钟 → OI权重回升，读Pin

一句话：盘中跟Volume，尾盘30分钟请回OI。

【GVP模型】
GEX（结构） + VWAP（成本） + 价格行为（趋势）
同向才动手，矛盾就不动。

【出场三档】
第一档：利润到心理预期50% → 减一半
第二档：触Call/Put Wall → 再减或全出
第三档：结构反转（破Flip/VWAP）→ 全走

【仓位自检（下单前10秒）】
1. 全损多少美元？占账户多少？
2. 止损/放弃点在哪？
3. 今天事件日？→ 更保守
4. 冷静还是想翻本？→ 后者不下单

连亏3笔 → 降仓或停手。大赚后72小时不加倍。

【假跌破 vs 真跌破】
假跌破：破一下 → 晃 → 快速收回
真跌破：破 → 不回 → 继续走

【事件日原则】
不猜数据好坏。控仓 + 等15-30分钟 + 认IV定价。

---

**日内节奏表**


| 时段          | Volume GEX | OI GEX   | 怎么用               |
| ----------- | ---------- | -------- | ----------------- |
| 盘前          | 低          | 高        | 标隔夜墙位             |
| 开盘 ~30 分钟   | ↑ 升        | ↓ 降      | 看成交重心是否偏离         |
| 10:00–15:00 | 主导         | 辅助       | Wall 跟 Volume 版   |
| 15:30–15:45 | 辅助         | 明显回升     | OI Wall 权重提高      |
| 15:45–16:00 | 参考         | 高（Pin 段） | OI 堆积 + Volume 共振 |


**一句话**：盘中跟 Volume 走，尾盘 30–15 分钟把 OI 请回来。

---

**三种场景**


| 场景         | 看什么                    | 关键动作       | 典型复盘              |
| ---------- | ---------------------- | ---------- | ----------------- |
| Put Wall   | 假跌破 vs 真跌破；正 / 负 Gamma | 等收回 + VWAP | 0213 收回 / 0326 真破 |
| Gamma Flip | 性格是否切换；是否站稳            | 等突破确认      | 0217 6810→6850    |
| Vanna 深 V  | IV 回落、GEX 绝对值缩小        | 先停追空       | 0227              |


**假跌破 vs 真跌破**


| 类型  | 特征                              |
| --- | ------------------------------- |
| 假跌破 | 破一下 → 晃 → 快速收回（Liquidity Sweep） |
| 真跌破 | 破 → 不回 → 继续走                    |


---

**仓位自检（下单前 10 秒）**

1. 这一笔全损多少美元？占账户多少？
2. 止损 / 放弃点在哪？
3. 今天是不是事件日？→ 是则更保守
4. 现在是冷静还是想翻本？→ 后者不该下单


| 阶段  | 倾向      |
| --- | ------- |
| 学习期 | 更小、更慢   |
| 连亏期 | 降档，不是提档 |
| 大赚后 | 72h 不加倍 |


---

**事件日 checklist**

- 高影响宏观事件？
- IV 明显高于近几日？
- 事件前计划：少开 / 不开？
- 公布后等 15–30 分钟再看 GEX / VWAP？

**原则**：不猜数据好坏；控仓 + 等结构 + 认 IV 定价。

---

**出场三档**


| 档   | 触发                         | 动作   |
| --- | -------------------------- | ---- |
| 一   | 第一目标 / 时间衰减明显              | 减一部分 |
| 二   | 动能枯竭（如碰 Call Wall 横盘）      | 再减   |
| 三   | 结构反转（破 Gamma Flip、VWAP 失守） | 余仓离场 |

## 四、一页纸口诀

**看完这本书，记住这 10 句话**

1. 别猜涨跌，先读性格——今天偏减震器（正 Gamma）还是加速器（负 Gamma）？
2. 三根线——Call Wall（天花板）、Put Wall（地板）、Gamma Flip（性格开关）。
3. 做市商不是庄家——他是被动对冲的机器，不赌方向。
4. 正 Gamma = 减震器（涨卖跌买，波动被压）；负 Gamma = 加速器（涨买跌卖，波动被放）。
5. 墙会动、会塌、会被穿——别当铁底铁顶。
6. Vanna = 恐慌降温后的机械反弹；Charm = 时间在改 Delta，横盘也在亏。
7. 收盘前别贪——Pin 会吸价格，Charm 在加速，Theta 在啃。
8. GVP（GEX + VWAP + 价格行为（趋势））同向才动手，矛盾就不动。
9. 仓位自定——单笔全损以「睡得着」为上限。不补仓，不摊平。
10. 大赚大亏之后——大亏后 24 小时、大赚后 72 小时。最值钱的动作往往是不动。
